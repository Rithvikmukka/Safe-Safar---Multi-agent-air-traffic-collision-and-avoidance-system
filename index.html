01 The Problem & Motivation

Modern airspace supports over 105,000 daily commercial flights, with up to 20,000 aircraft airborne simultaneously. Centralized human controllers face acute cognitive saturation — contributing to the 1,757 FAA near-miss incidents recorded in 2024 alone. A root-cause study of 85 incidents identified three dominant failure modes: improper aircraft spacing (30.5%), failure to intervene in time (28.4%), and improper control handoffs (27.8%).

Safe Safar resolves this bottleneck by distributing intelligence to each aircraft. Instead of one controller managing thousands of planes, each aircraft autonomously perceives, negotiates, and reroutes without central coordination — a truly decentralized multi-agent system.

02 AI Agent Formalization — PEAS Framework

Performance Zero mid-air collisions (absolute constraint). Enforce minimum safe separation (>34 NM / vertical ΔFL ≥ 20). Minimize fuel burn, detour distance, and arrival delay. Reach assigned destination gate safely.
Environment Dynamic continuous 2D/flight-level airspace graph with aeronautical waypoint fixes (KODEX, ELKEY, etc.), variable traffic density, and active flight paths.
Actuators Waypoint heading vector changes · Cruise speed throttling (35–65 kts) · Flight level / altitude adjustment · Dynamic A* route replanning · Aeronautical holding pattern loiter orbits
Sensors Internal Telemetry: GPS position, velocity, remaining fuel, destination.
Forward Radar Transponder: 72° forward cone, 165 NM range — perceives peer positions, speeds, headings, and flight levels. Omnidirectional Transponder Bubble: 51 NM proximity alert for blind-spot overtake scenarios.

03 Environment Classification

Multi-Agent (Mixed-Motive)
Multiple planes act concurrently. All cooperate to avoid collisions, but compete selfishly for the most fuel-efficient route.
Partially Observable
Agents perceive only what enters their forward radar cone — no omniscient global map. Simulates realistic limited-range avionics.
Dynamic
The state changes continuously while agents compute their next moves. A reroute by one agent immediately alters the conflict landscape for others.
Continuous
Positions, velocities, headings, and fuel burn rates exist in continuous real-number space — not a discrete grid.
Sequential
An avoidance maneuver now directly affects future encounters downstream. Decisions are interdependent across time.
Stochastic
Traffic generation rates, speed fluctuations, and turn delays introduce non-deterministic variance in the environment.

04 Agent Decision Cycle

👁 Sense → 📡 Detect Conflict → 🤝 P2P Negotiate → 🧭 A* Replan → ✈ Act → 🔁 Re-observe

Agents do not wait for a collision — they use forward temporal projection over discrete lookahead samples (t = 2s, 4s, 6s, 8s). If predicted positions breach the 34 NM safety radius at any future timestamp, a Hazard Point is flagged at that coordinate.

05 Objective Cost Function

Cost = (CollisionRisk × LargePenalty) + wd·Distance + wf·Fuel + wt·Delay The collision penalty term strictly dominates all others — guaranteeing that no rational agent ever selects a risky shortcut for fuel or schedule savings.

06 Conflict Resolution Scenarios

A
Pairwise Head-On Conflict Two aircraft detect mutual approach via overlapping radar cones. P2P negotiation fires. Higher-priority agent holds course; lower-priority agent executes local A* detour around the hazard point cluster.
B
3-Way Convergence (Cluster Conflict) Three or more agents converge on the same waypoint. Union-Find clustering groups them by shared conflict graph component. Agents are sorted by priority and rerouted sequentially — highest first, lowest waits.
C
All Exits Blocked → Aeronautical Holding Pattern If every detour A* proposes violates the hard geometric safety gate, the agent anchors over the nearest waypoint fix and enters a safe loiter orbit until crossing traffic clears.
D
Deterministic Tie-Breaking If two agents share exactly the same priority score, their unique aircraft IDs serve as a final deterministic tiebreaker — eliminating all possibility of logical deadlock.
E
Fuel Starvation Priority Override A plane with critically low fuel receives a boosted fuel-urgency priority score that overrides any mission-type advantage — safety beats VIP status, always.

All constants are calibrated to balance computational tractability with realistic aeronautical separations.

Formula 01 · Priority Score

Agent Priority Scoring

P = Ufuel + 0.4 · wp

Fuel Urgency Ufuel scales up to 60 pts; mission importance wp scales to 40 pts. A critically low-fuel commercial flight always outranks a fully fueled VIP aircraft — safety beats status.

  • Ufuel = max(0, 60 · (1 − fuel / max_fuel))
  • wp ∈ [0, 100] assigned per flight type
Formula 02 · A* Avoidance Penalty

Repulsive Potential Field

Penalty(n) = (PenaltyRadius − d(n, hazard)) × 14

Applied only when d < 95 NM. Creates a mathematical "hill" forcing A* to route around the hazard perimeter. The closer a candidate waypoint is to the epicenter, the steeper the artificial cost cliff.

  • At d = 90 NM → +70 units penalty
  • At d = 50 NM → +630 units penalty
  • At d = 5 NM → +1,260 units penalty
Formula 03 · A* Cost Function

Informed Search with Euclidean Heuristic

f(n) = g(n) + Penalty(n) + h(n)

h(n) = dist(n, goal)

Euclidean straight-line distance is an admissible and consistent heuristic (h(n) ≤ h*(n)), guaranteeing optimal path length. Penalty(n) is an inadmissible additive term that trades strict optimality for guaranteed safety separation.

Formula 04 · Objective Cost

Multi-Objective Agent Utility

Cost = (CollisionRisk × λpenalty) + wd·Distance + wf·Fuel + wt·Delay

The collision penalty term strictly dominates all others — guaranteeing 100% safety separation as the highest objective.

Formula 05 · Temporal Projection

4D Lookahead Conflict Detection

∀ t ∈ {2s, 4s, 6s, 8s}:
dist(PA(t), PB(t)) < 34 NM ⟹ CONFLICT

Agents compute their predicted positions at 5 discrete future timestamps. Each timestamp where two planes will be too close generates one hazard point. A* then routes around the entire hazard cluster.

Formula 06 · Separation Invariant

Hard Safety Geometric Gate

∀ seg ∈ newPath, ∀ pt ∈ hazards:
dist(seg, pt) < SAFETY_RADIUS × 0.92 ⟹ REJECT

After A* proposes a detour, every waypoint is checked against every hazard point. A single violation causes the entire proposed route to be rejected — triggering a holding pattern fallback.

Architecture Comparison

Criterion Centralized ATC Safe Safar (Decentralized Multi-Agent)
Early Conflict Detection Global visibility hours ahead — high false positive rate due to weather/trajectory drift Local-horizon ground truth (10–15 min), high-confidence tactical detection
Computational Complexity NP-Hard combinatorial global optimization (O(N!) for N flights) Linear O(N) local computation per conflict cluster
Resilience / SPOF Single ground-server failure blacks out entire airspace sector Zero SPOF — each agent operates autonomously on board
Coverage Requires continuous ground radar and datalink infrastructure Peer-to-peer ADS-B works over oceans, mountains, remote regions
Best Application Strategic slot allocation, macro corridor planning, airport sequencing Tactical real-time deconfliction, UAM drone swarms, oceanic airspace
Real-World Architecture: The Hybrid Tier Model The gold standard in modern aviation is a 4-tier hybrid: (1) Centralized strategic flow management (hours ahead), (2) Regional trajectory-based operations (10–30 min), (3) Decentralized multi-agent tactical deconfliction (1–10 min — the Safe Safar tier), and (4) Hard-wired autonomous reflex (TCAS/ACAS X, 15–45 sec). Safe Safar operates at Tier 3, where centralized predictions become unreliable and peer-to-peer edge autonomy is the only scalable solution.
